# Project Overview
          • This project builds an Intrusion Detection System (IDS) leveraging machine learning to detect ransomware  network behavior, using the UGRansome dataset.
          •  The main objective of this project is to detect and classify potential cyber threats from network traffic data using machine learning. The model analyzes network parameters such as protocol type, port number, malware family, and transaction information to identify whether the activity is safe or suspicious.
